# Call script (30 seconds)
"Hi, is this {{first_name}}? I'm {{your_name}}, a local web designer. I built a free sample website for {{business}} because I noticed {{no site / yours is hard to use on a phone}}. Can I text or email you the link? If you hate it, delete it, no strings."

Objections
- "We get work by referral." > "Great, a site also makes referrals easier to verify. It only takes a minute to look."
- "Too expensive." > Offer the Starter tier or a monthly plan.
- "Already have a guy." > "No problem. Keep the link in case it's useful."
